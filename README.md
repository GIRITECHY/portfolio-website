# Portfolio Website

A modern, animated portfolio website built with HTML, CSS, and JavaScript featuring GSAP animations and a beautiful dark/light theme.

## Features

- 🎨 **Modern Design** - Clean, professional interface with gradient accents
- 🌓 **Dark/Light Theme** - Toggle between themes with persistent storage
- ✨ **Smooth Animations** - GSAP-powered scroll animations and transitions
- 📱 **Fully Responsive** - Works perfectly on all devices
- ⚡ **Fast Performance** - Optimized for speed
- 🎯 **SEO Optimized** - Includes robots.txt and sitemap.xml

## Sections

- **Hero** - Eye-catching introduction with typing animation
- **About** - Personal introduction and skills showcase
- **Projects** - Portfolio of featured work
- **Contact** - Get in touch section with contact information
- **Footer** - Social media links

## Technologies Used

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript (ES6+)
- GSAP (GreenSock Animation Platform)
- Google Fonts (Inter)

## Customization

### Update Personal Information

1. **Name & Title**: Edit the text in `index.html`
2. **Contact Info**: Update email, phone, and location in the Contact section
3. **Social Links**: Replace placeholder URLs in the footer
4. **Projects**: Add your own projects in the Projects section
5. **Skills**: Modify the skill tags in the About section
6. **Profile Image**: Replace the SVG placeholder with your photo

### Update Colors

Edit the CSS variables in `style.css`:

```css
:root {
    --color-primary: #667eea;
    --color-secondary: #f093fb;
    --color-accent: #4facfe;
}
```

### Update Typing Animation

Edit the words array in `main.js`:

```javascript
const words = ['Developer', 'Designer', 'Creator', 'Problem Solver'];
```
